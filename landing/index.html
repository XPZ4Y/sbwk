Deployment & Docs

SBWK (Sleepy Bot with Keys) is a zero-dependency anomaly-detecting middleware with an integrated AI diagnostic agent.

It sits directly between your users and your application server. It passively monitors traffic, intelligently detects anomalies without arbitrary thresholds, extracts logs, metrics, and codebase context, and provides actionable, diff-ready solutions via Liquid AI and Groq.

Quick Start 

# 1. Download configuration templates
curl -O https://raw.githubusercontent.com/XPZ4Y/sbwk/main/docker-compose.yml
curl -O https://raw.githubusercontent.com/XPZ4Y/sbwk/main/.env.example

# 2. Setup your environment variables
mv .env.example .env   # then edit the secrets inside

# 3. Pull images and launch the stack
docker compose pull
docker compose up -d

Documentation Overview

Middleware (Edge)

Reverse proxy that intelligently detects anomalies (500s, slow responses) and dispatches them without halting traffic.

Agent Core

The AI reasoning engine. Uses Liquid d1 for rapid triage and Groq for generating root cause analysis and git-patch fixes.

Agent Connector

Read-only diagnostic tool that safely pulls metrics and logs from your DBs, Auth, and External APIs for the AI.

Control Plane

The UI dashboard for configuring the stack, setting safety limits, and monitoring the live AI diagnostic feed.
